# 运动员运动学指标表

数据来源：`41_coordinates.csv`。位置由像素坐标经球场单应性转换为米制坐标；运动员速度超过 8.5 m/s 的相邻帧跳变被排除。`near_id` 和 `far_id` 按用户定义分别代表近端和远端运动员。

\* 减速次数定义为相邻有效速度差对应的加速度小于 `-1.0 m/s²` 的次数。区域比例依据单应性后的球场纵向三等分和横向中线计算。加速度仍对坐标抖动敏感，适合做相对比较，不宜作为生理负荷的直接测量。
