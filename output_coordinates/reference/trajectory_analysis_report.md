## 添加数据的方法

1. **人工轨迹真值**：对每帧增加 `gt_ball_x, gt_ball_y, gt_ball_visible, gt_near_x, gt_near_y, gt_far_x, gt_far_y`；至少抽取全视频 10% 帧，并覆盖快速移动、遮挡和出界片段。这样可计算 MAE、RMSE、PCK、Precision、Recall、F1、ADE 和 FDE。
2. **身份真值**：增加 `gt_player_id`，并在每帧将检测轨迹与真实身份对应；这样才可计算 IDF1、MOTA 和 ID Switches。
3. **回合边界**：增加 `rally_id, rally_start, rally_end`，每帧标记所属回合；这样可计算每回合时长、球员距离、球速和回位时间。
4. **击球事件**：增加 `hit_event, hitter_id, hit_type, landing_event`，记录击球帧、运动员、击球类型和落点；这样才能分析击球次数、击球类型和落点分布。
5. **三维数据**：使用双目/多视角相机或深度相机，并提供相机内外参数；这样才能估计真实三维轨迹、球高和三维速度。

## 解释注意事项

- 覆盖率表示坐标文件中存在有效值的比例，不等于检测准确率。
- 本报告的速度和距离是二维单应性投影结果；异常跳变过滤阈值应在论文方法中预先说明。
- 当前近端/远端是画面位置角色，不应直接解释为具体运动员姓名。
